Privacy at vercel.school

vercel.school is an independent site operated by Adam Pang. This policy describes the information processed when someone browses the public classroom, voluntarily joins the email update list, or chooses an external contact link.

Public-site analytics

The public page loads Vercel Web Analytics from the site's own Vercel deployment. Vercel may process request and performance information needed to host the site and report aggregate usage; the initial HTML response does not set a cookie.

Optional email updates

The subscribe form collects only the email address a visitor submits. The server normalizes that address and stores it with the source “vercel.school” in a shared subscriber database provided through Neon, so Adam can send the occasional shipping updates described beside the form.

External services and links

Vercel provides hosting and analytics, while Neon provides the database used for optional subscriber addresses. Product links, email links, and the X profile leave vercel.school; those destinations apply their own privacy practices after a visitor chooses to open them.

Choices and removal

Browsing the classroom does not require an account or subscription. To request removal of an email address from the update list, use the public address on the contact page and identify the address that should be removed.

Policy changes

Material changes to what vercel.school collects or how the listed services are used should be reflected on this page. The effective date above identifies the version currently published with the site.
